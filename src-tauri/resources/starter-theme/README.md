# Starter theme

Created with ChannelCraft Studio. It is a small EmulationStation (RetroBat) theme to build on:

- `theme.xml` defines the system view and the game list views.
- `_inc/colors/` holds the colour sets offered in RetroBat's theme options.
- `_inc/images/` holds the artwork.

Add system logos at `_inc/logos/<system>.svg` and point the `logo` image at `./_inc/logos/${system.theme}.svg` to replace the text titles.
